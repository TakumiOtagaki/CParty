# Handoff (2026-02-16)

## 概要
- 目的: SCFG の rule-based API 化に向けて、既存 DP を rule-runtime 経由で動かす段階的移行を完了。
- 現状: `rules_runtime` で **全非終端(V/W/VM/WI/WMv/WMp/WM/WIP/VPL/VPR/VP/WMBW/WMBP/WMB/BE)** を rule-mode 経由で計算できる状態。
- テスト運用: rules+debug フル / legacy 100 比較 を都度実行。

## 実装の主要ポイント
### 1) Rule API の型定義
- `src/scfg/rules_api.hh`
  - `NonTerminal`, `RuleId`, `SplitKind`, `SplitSpec`
- `src/scfg/rules_api.cc`
  - `rule_id_name` / `parse_rule_id`

### 2) ルール実行モードとデバッグ
- `src/scfg/rules_engine.hh/.cc`
  - `SCFG_RULES_MODE=rules` で rule-runtime を有効化
  - `SCFG_RULES_DISABLE` (CSV) で個別ルール無効化
  - `SCFG_RULES_ONLY` (CSV) で有効ルール限定
  - `SCFG_RULES_DEBUG=1` で stderr に設定とルール hit カウントを出力
- **修正点**
  - `SCFG_RULES_ONLY` が空文字の場合は有効化しない（全ルール無効化を防止）
  - ルール hit カウントは atexit で出力（heap 確保で segfault 回避）

### 3) rules_runtime 実装（DP 全系統）
- `src/scfg/rules_runtime.hh/.cc`
  - `V/W/VM/WI/WMv/WMp/WM/WIP/VPL/VPR/VP/WMBW/WMBP/WMB/BE` を移植済み
  - `record_rule_hit` で実行回数を計測
- `src/scfg/part_func_adapter.cc`
  - rule/legacy の切替を全 compute_* に実装

### 4) BE 条件の統一
- `W_final_pf::get_BE` の条件を `pair > 0` に統一（legacy 仕様に合わせた）
  - 位置: `src/part_func.hh`

## 重要な環境変数
- `SCFG_RULES_MODE=rules` : rule-runtime を有効化
- `SCFG_RULES_DEBUG=1` : rules hit カウントを stderr 出力
- `SCFG_RULES_DISABLE=A,B,...` : RuleId を無効化
- `SCFG_RULES_ONLY=A,B,...` : RuleId を限定（空文字は無視するようにガード済み）
